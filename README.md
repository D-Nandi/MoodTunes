# MoodTunes
MoodTunes is an AI-powered cinematic music discovery platform that delivers emotionally intelligent song recommendations based on mood, atmosphere, and personalized listening behavior.

✨ Features
🎭 Mood-based music recommendations
🧠 Semantic emotional understanding
🎧 Personalized recommendation engine
🌌 Cinematic dark UI with animated ambience
💡 AI Match confidence scoring
🚫 Anti-tag filtering system
📊 Weighted recommendation scoring
🕒 Recent mood tracking
🌍 Multi-language music discovery
⚡ Smooth premium animations

🎨 UI & Experience
MoodTunes features:
Cinematic glassmorphism UI
Ambient mood-reactive lighting
Smooth transitions and animations
Dynamic emotional atmosphere
Premium dark aesthetic
Each selected mood creates its own animated emotional ambience across the interface.

🛠️ Tech Stack
HTML5
CSS3
Vanilla JavaScript
Last.fm API
Semantic mood engine
Custom recommendation algorithms
